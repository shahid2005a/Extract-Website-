📦 Installation Guide

📱 Termux (Android) – Direct Download (No Git Clone)

```bash
pkg update && pkg upgrade -y
termux-setup-storage
pkg install python -y
pkg install wget -y
pkg install curl -y
pip install requests pyTelegramBotAPI
wget https://raw.githubusercontent.com/shahid2005a/Extract-Website-/main/main.py
python main.py
```

🐧 Linux (Ubuntu/Debian/Kali) – Direct Download

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install python3 python3-pip wget curl -y
pip3 install requests pyTelegramBotAPI
wget https://raw.githubusercontent.com/shahid2005a/Extract-Website-/main/main.py
python3 main.py
```

🟡 Linux (Fedora/RHEL)

```bash
sudo dnf update -y
sudo dnf install python3 python3-pip wget curl -y
pip3 install requests pyTelegramBotAPI
wget https://raw.githubusercontent.com/shahid2005a/Extract-Website-/main/main.py

```

⚡ Single Command Installation (Termux)

```bash
pkg update && pkg upgrade -y && termux-setup-storage && pkg install python wget curl -y && pip install requests pyTelegramBotAPI && wget https://raw.githubusercontent.com/shahid2005a/Extract-Website-/main/main.py && python main.py
```

📖 Usage Guide

🔹 Website Extractor (Terminal)

1. Run python main.py
2. Enter the website URL (e.g., https://example.com)
3. Tool will extract HTML, CSS, and JavaScript
4. All files are saved as a ZIP in /storage/emulated/0/Dgtl/ (Android) or current directory (Linux)

Example Output:

```
🌐 Extracting: https://example.com
⏳ Connecting to server...
📄 HTML saved: index.html
🎨 Extracting CSS files...
  ✅ CSS: style_0.css
  ✅ CSS: style_1.css
📊 Extracted 2 CSS files
📜 Extracting JavaScript files...
  ✅ JS: script_0.js
📊 Extracted 1 JavaScript files
✅ Extraction successful!
📦 ZIP: /storage/emulated/0/Dgtl/example.com_website.zip (5.81 KB)
```

🔹 Dgtl Folder(Sever)

  · download <file> – Download file
  
  · 🌐 Extract Website – Trigger
